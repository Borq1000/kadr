# Библиотека эффектов, этап E2 (Looks и Виньетка): стоимость и приёмка

Записано 2026-10-11 на ветке `feature/effects` (Task 9). Цель из спецификации (§9): Look + движение на 1080p укладываются в бюджет кадра на CPU (33,3 мс при 30 fps, 16,7 мс при 60 fps); вычислитель — в планке ≤ 100 µs на `evaluate`. Числа скопированы из сырого вывода `kadr-bench` и `get_perf`.

Живое воспроизведение — на release-сборке 217afe0, без параллельных сборок.

## 2. Рендер (полный кадр, CPU)

Строка «1 layer + Look» — один полнокадровый слой с Look «Винтаж» при силе 100 %: коррекция, кривая, split-tone, виньетка, зерно — все пять точечных операций за один проход. Она же стоит за «Look + движение»: любой эффект уже выключает быстрый путь копирования, и слой идёт общим путём с выборкой — тем же, что у движения (масштаб, сдвиг, поворот); стоимость движения в пикселях — это стоимость самой выборки («1 layer scaled»). Миллисекунды, p50 / p90 / max; во всех строках 0 аллокаций кадра и 0 новых буферов пула.

| прогон | 1080p: 1 layer scaled | 1080p: 1 layer + Look | 4K: 1 layer scaled | 4K: 1 layer + Look |
|---|---|---|---|---|
| 1 | 7,43 / 8,19 / 12,28 | 17,25 / 18,34 / 19,37 | 28,48 / 30,96 / 43,14 | 68,53 / 73,20 / 80,08 |
| 2 | 7,32 / 7,69 / 8,28 | 17,23 / 18,29 / 24,77 | 28,70 / 30,38 / 32,26 | 68,36 / 71,92 / 80,28 |
| 3 | 7,34 / 7,71 / 8,55 | 17,24 / 18,43 / 19,63 | 28,83 / 29,81 / 38,14 | 68,19 / 70,89 / 88,69 |

Цепочка Look стоит ≈ 9,9 мс на кадр 1080p и ≈ 39,7 мс на кадр 4K (Look / scaled ≈ 2,34× и 2,38×). По отдельности (p50, 1080p, база 8,22 мс): коррекция +0,65, кривая +2,75, split-tone +1,51, виньетка +2,63, зерно +3,47 мс. Модель стоимости (`cost.rs`) перекалибрована по этим числам: коррекция 0,2, кривая 0,45, split-tone 0,25, виньетка 0,4, зерно 0,5 доли прохода; полный Look предсказывается как 2,8 против ≈ 2,3 по замеру — класс тот же (`Medium`). Подряд идущие коррекции считаются один раз (рендерер складывает их в одну матрицу).

## 4. Пиксели и сверка

- Сверка CPU с эталонным f64-рендерером: 2000 случайных сцен (цепочки до пяти примитивов, в том числе тождественные кривые рядом с сильной экспозицией, виньетка и зерно на letterbox-выводе), плюс детерминированный тест всех шести Looks при силе 60 % и 100 % на горизонтальном и вертикальном холсте, на масштабированном и «коробочном» выводе, на полнокадровом слое и повёрнутой «картинке в картинке»: расхождение не больше 1 LSB (2 — только на пикселях-«ничьих» округления).
- Эталонные PNG: по одному на каждый примитив (кривая, split-tone, виньетка, зерно) и на каждый Look; нейтральные параметры, сила 0 и выключенный эффект дают кадр, побайтно равный кадру без эффекта, и сохраняют быстрый путь копирования.
- Разрез клипа с Look: каждый пиксель обеих половин равен неразрезанному клипу на том же кадре, зерно включительно; зерно меняется от кадра к кадру.
- Look виден на обеих сторонах растворения; «До» показывает клип без Look; предпросмотр наведением несёт цвет Look.

## 5. Вердикт

**Цель выполнена.**
- Рендер: полный кадр 1080p с самым тяжёлым Look — p90 ≤ 18,4 мс, в бюджете 30 fps (33,3 мс) с запасом ≈ 1,8×; бюджет 60 fps (16,7 мс) в полном разрешении не выдерживается (18,3 мс), но превью идёт в половинном разрешении (960×540, ≈ 4,7 мс по замеру Task 2), а экспорт не обязан быть в реальном времени. 4K ≈ 69 мс на кадр — на уровне строк 4K из M2, для экспорта.
- Живое воспроизведение (release, клип 1920×1080 30 fps, превью ½, 12 с с 20-й секунды, `get_perf` со сбросом):

  | | композит p50 / p90 / p99, мс | потеряно кадров | время кадра p50 / p90, мс |
  |---|---|---|---|
  | без эффектов | 0,40 / 0,54 / 0,96 | 1 из 378 (0,26 %) | 31,3 / 32,2 |
  | Винтаж + Ручная камера + Плавный наезд | 5,83 / 6,45 / 10,61 | 1 из 379 (0,26 %) | 31,4 / 32,5 |

  Потерь не больше, чем без эффектов; время кадра — темп воспроизведения 30 fps.
- Вычислитель: ≤ 34 µs при планке 100 µs.
- Адаптивный регулятор качества превью (спецификация §0) не нужен: замер в бюджете.

### Замечания приёмки

- Найдено и исправлено по ходу: растянутое поле поиска (54b8cc6), список пресетов не применял выбор (80c5316), пункты верхнего меню не срабатывали по клику — старая ошибка с V0.1 (e5248de).
- Вопросы владельцу: значения шести пресетов (особенно Тёплый и бирюзовые тени Кино); виньетка Look на «картинке в картинке»; зерно на миниатюрах 160×90 почти не видно (ячейка меньше пикселя карточки).
- Старое, не E2: при окне 1024 × 640 таймлайн сохраняет высоту из большого окна, и сетке карточек остаётся одна строка; AI-панель обрезана правым краем (B2 из E1).
