# Kadr — система эффектов: примитивы, рецепты, пресеты

Дата: 2026-09-30 · Статус: **черновик на согласование**. Реализация эффектов
начинается только после фундамента рендеринга
([архитектура рендеринга](2026-09-30-render-architecture-design.md), этапы M0–M6).

## 0. Принципы (от владельца продукта)

- **Professional-looking results without professional-level complexity.**
  Простота уровня CapCut, качество результата выше, нативная скорость.
- Не After Effects, не комбайн, не копия Vegas. **Не много эффектов, а 30 хороших.**
- Типичная операция: выбрал клип → выбрал эффект → сразу хорошо → при желании
  2–5 понятных параметров. Advanced существует, но не обязателен.
- Фильтр для каждой новой функции:
  1. Пользуются регулярно?
  2. Профессиональный результат без сложной настройки?
  3. Эффективно, без утяжеления?

  Два «нет» — не делаем.
- AI — необязательный слой поверх обычного движка; тяжёлые модели грузятся
  лениво и не висят в памяти.

## 1. Что есть сейчас

- В модели: `Clip.effects: Vec<{ kind: String, params: BTreeMap }>` и
  `Clip.keyframes: Vec<{ property: String, … }>` — **не вычисляются нигде**.
- Реально работает только:
  - `ColorAdjust` (экспозиция, контраст, насыщенность; «температура» не
    применяется) — и только в экспорте (`eq` FFmpeg); превью цвет не показывает;
  - три перехода (`xfade` fade / fadeblack / wipeleft), только в экспорте;
  - звук: gain, pan, fade in/out (Rust-микшер в превью, фильтры FFmpeg в экспорте).
- Пресетов, рецептов, анимации, живого предпросмотра эффектов нет. Undo есть
  (`EditEngine`, пакеты команд).

## 2. Слои системы

```
Намерение пользователя / AI ("сделай плавный дорогой наезд")
        │  AI превращает в обычную команду редактора
        ▼
Recipe + параметры (CinematicPush { strength: Normal, anchor: Subject })   ← хранится в проекте
        │  compile (CPU, в evaluator, каждый кадр — дёшево)
        ▼
Анимационные примитивы (Tween, Easing, Noise, TimeRemap)                    ← CPU
        │  вычислены на момент t
        ▼
Примитивы рендера в FrameScene (Placement, ColorAdjust, ToneCurve, Blur…)   ← данные
        │
        ▼
Renderer (CPU — эталон и fallback; wgpu — цель для realtime)
```

- **Рецепты никогда не доходят до рендерера.** Рендерер знает примерно 15
  примитивов, а не 30 эффектов. Новый эффект — обычно новый рецепт без нового
  шейдера.
- **Пресет** — именованный набор значений параметров рецепта. Все Looks — это
  пресеты одного рецепта «Look»; их можно задать данными (JSON в репозитории),
  без кода.

## 3. Примитивы рендера

| Примитив | Класс (§7) | Параметры (в пикселях холста, где есть размеры) | CPU | GPU |
|---|---|---|---|---|
| `Placement` (+ crop, opacity) | геометрия | position, anchor, scale, rotation; crop rect | да | да |
| `ColorAdjust` | точечный | exposure, contrast, saturation, temperature, tint | да | да |
| `ToneCurve` | точечный | до 5 точек по яркости или по каналам → LUT 256 | да | да |
| `SplitTone` | точечный | оттенок и сила для теней и светов, баланс | да | да |
| `Vignette` | точечный | amount, midpoint, feather (круг в пикселях холста, aspect-correct) | да | да |
| `Grain` | точечный | amount, size, seed (детерминированный целочисленный хэш — одинаков на CPU и GPU) | да | да |
| `Blur` | окрестностный | radius (гаусс, раздельный) | медленно | **предпочтительно** |
| `Bloom` | окрестностный | threshold, radius, strength, tint (пирамида уменьшений) | медленно | **предпочтительно** |
| `MotionBlur` | геометрия × N | shutter (доля кадра); берёт `Layer.motion` — положения слоя на открытии и закрытии затвора | медленно | **предпочтительно** |
| `Gradient` (генератор) | генератор | linear / radial, цвета, позиция | да | да |
| `Noise` (генератор) | генератор | мягкий шум для light leak, seed | да | да |
| `Mix` (переход) | смешивание | progress; варианты `Dissolve`, `DipToColor`, `Wipe { angle, softness }` | да | да |
| `Mask` (позже) | точечный (покрытие) | rect / ellipse / rounded, feather, invert | да | да |
| `Text` (позже, подпроект титров) | генератор | текст, шрифт, стиль → растеризация на CPU, кэш как текстура | растеризация | композиция |

Переходы «со сдвигом» (Push, Whip, Zoom Through) — не отдельные пиксельные
операции. Evaluator двигает `Placement` обоих клипов, а размытие даёт общий
`MotionBlur` по фактическому движению. Так один примитив покрывает и
наезды, и резкие переходы.

### Примитивы цвета

Над непремультиплицированными нелинейными Rec.709 значениями `c ∈ [0,1]³`
(рабочее пространство — §6 архитектуры рендеринга). Порядок внутри
`ColorAdjust` фиксирован.

1. **Exposure** (ev, в ступенях), в линейном свете с чистой степенью 2,4:
   `c' = (c^2.4 · 2^ev)^(1/2.4)` (на CPU — таблица 256 на канал, на GPU —
   `pow`; допуск ±1 LSB).
2. **Contrast** k вокруг 0,5: `c' = (c − 0.5)·k + 0.5`.
3. **Temperature** t ∈ [−1, 1], **tint** u ∈ [−1, 1]:
   `R·(1 + 0.1t)`, `B·(1 − 0.1t)`, `G·(1 − 0.05u)`.
4. **Saturation** s: `Y = 0.2126R + 0.7152G + 0.0722B`, `c' = Y + (c − Y)·s`.
5. Ограничение в [0, 1] — **один раз в конце** слитой цепочки точечных операций.

- **ToneCurve**: монотонный кубический сплайн (Fritsch–Carlson) по точкам →
  таблица 256 (CPU — массив, GPU — 1D-текстура из той же таблицы: одинаковый
  результат).
- **Vignette**: `v = 1 − amount · smoothstep(mid, 1, d)`, где `d` — расстояние
  от центра холста в пикселях, делённое на половину диагонали.
- **Grain**: `c' = c + (hash(x, y, frame, seed) − 0.5) · amount · w(Y)`,
  хэш PCG32 на целых числах.

## 4. Анимационные примитивы (CPU, в evaluator)

- `Tween<T> { from, to, start, end, easing }` для любого числового параметра
  или `Placement`.
- `Easing`: `Linear`, `Smooth` (cubic in-out), `Cinematic` (cubic-bezier
  0.45, 0, 0.2, 1), `Snap` (expo-out, для punch и whip), `Gentle` (sine),
  `Spring` (затухающая пружина).
- `Noise1D { seed, frequency, amplitude }` — плавный шум для «ручной камеры» и
  «парения».
- `TimeRemap` — кривая скорости → точное время источника (`Time`, без
  накопления f64): для Speed Ramp.
- **Дорожка ключевых кадров** (Level 3) — последовательность `Tween`. Рецепт
  можно «отвязать» (Detach) в явные дорожки и править вручную.

## 5. Recipe и Preset

```rust
// Реестр — код (kadr-effects). Логика рецепта — функция compile.
pub struct RecipeDef {
    pub id: &'static str,              // "cinematic_push"
    pub category: Category,            // Motion | Transition | Look | Light | Text | Audio
    pub target: Target,                // Clip | Cut | TextClip | AudioClip
    pub version: u16,
    pub params: &'static [ParamDef],   // 0–5 параметров Level 2
    pub cost: CostClass,               // Cheap | Medium | Heavy
    pub compile: fn(&Params, &CompileCtx) -> Compiled,
}
pub struct ParamDef { pub key: &'static str, pub kind: ParamKind, pub default: ParamValue }
pub enum ParamKind {
    Strength,           // Subtle / Normal / Strong (внутри 0..1)
    Duration,           // Time
    Direction,          // ← → ↑ ↓ / In/Out
    Point,              // точка на кадре (ставится мышью на превью; AI может предложить лицо)
    Color, Choice(&'static [&'static str]),
}
pub struct Compiled {
    pub placement: Vec<Anim<PlacementDelta>>,   // масштаб, смещение, поворот во времени
    pub effects: Vec<Anim<Effect>>,             // примитивы, параметры могут анимироваться
    pub motion_blur: Option<f32>,               // доля затвора
    pub transition: Option<TransitionBuild>,    // для target = Cut
    pub audio: Vec<AudioOp>,                    // для звуковых рецептов
}

// В проекте хранится намерение, а не развёрнутые примитивы:
pub struct AppliedEffect {
    pub id: EffectId,
    pub recipe: RecipeId,                        // "cinematic_push"
    pub version: u16,
    pub params: BTreeMap<String, ParamValue>,    // проверяются по RecipeDef при загрузке
    pub enabled: bool,
    pub span: Option<TimeRange>,                 // по умолчанию — весь клип (или длительность рецепта)
    pub detached: Option<Detached>,              // Level 3: явные дорожки и примитивы
}
```

- Проект не зависит от реестра: хранит id и значения. Неизвестный рецепт при
  загрузке сохраняется как есть (не теряется) и помечается «недоступен».
- **Версии**: если рецепт заметно меняет вид, старая `compile` остаётся под
  своим номером — старые проекты выглядят как раньше. Мелкие улучшения идут
  без новой версии.
- **Пресеты Looks** — данные: `looks.json` с точками кривой, split-tone,
  виньеткой, зерном и bloom для «Cinematic», «Warm» и т. д.
- Crate `kadr-effects` (реестр, easing, кривые, compile) зависит от
  `kadr-core` и `kadr-scene`; им пользуется evaluator в `kadr-timeline`.

## 6. Как Recipe становится FrameScene (пример)

```
Clip + [AppliedEffect(cinematic_push {strength: Normal, anchor: (0.62, 0.40)}),
        AppliedEffect(look {preset: "luxury", strength: 0.7})]
        │ evaluate(t)
        ▼
base = Placement из Clip.transform
cinematic_push.compile → scale Tween 1.00→1.05 (Normal), Easing::Cinematic, на весь клип,
                         anchor из параметра, motion_blur 0.25
p(t) = base ∘ tween(t)                         → Layer.placement
motion = (p(t − ½·затвор), p(t + ½·затвор))    → Layer.motion (только если движение > 0,5 px)
look.compile  → [ToneCurve(lerp(identity, luxury.curve, 0.7)),
                 SplitTone(…·0.7), Vignette(…·0.7), Grain(…·0.7), Bloom(…·0.7)]
                                               → Layer.effects (нулевые — отброшены)
```

**Strength** — единая семантика: линейная интерполяция параметров примитивов
от нейтральных к пресету; `Strong` может немного превышать пресет (1,3×).
Переход на склейке: рецепт перехода строит
`LayerContent::Transition { from, to }`, двигая placement обоих клипов, с
`Mix` и `MotionBlur`.

## 7. Уровни качества

Одна визуальная модель; качество меняет только точность.

| Примитив | PreviewFast | PreviewHigh | Export |
|---|---|---|---|
| Blur | в ½ разрешения, раздельный | полное разрешение | полное, ядро 3σ |
| Bloom | 3 уровня пирамиды | 5 | 6 |
| MotionBlur | 4 сэмпла | 8 | 16 |
| Grain, точечные операции | как Export | как Export | эталон |
| Текст | растр в размере вывода | то же | то же |

Все размеры — в пикселях холста и масштабируются к выводу, поэтому превью ½
выглядит как экспорт.

## 8. Адаптивное превью

`PreviewGovernor` в `kadr-playback`:
- **Бюджет** — длительность кадра последовательности. Меряем p90 полного
  времени кадра по последним 30 кадрам (телеметрия §10 архитектуры).
- **Лестница деградации** (по одному шагу, эффекты не выключаем):
  1. качество эффектов PreviewHigh → PreviewFast;
  2. разрешение: выбранное пользователем → ½ → ¼;
  3. (позже) кэш рендера для тяжёлых участков.
- **Гистерезис**: понижение — если 5 из 10 кадров вне бюджета; повышение —
  после 60 кадров подряд ниже 70 % бюджета.
- **Упреждение**: на старте воспроизведения оценка стоимости сцены (сумма
  `cost` примитивов × пиксели) сразу выбирает стартовую ступень.
- **Пауза**: кадр перерисовывается в PreviewHigh и выбранном разрешении
  («доводка»).
- Экспорт всегда в Export и полном разрешении, регулятор не участвует.
- В UI индикатор: «½ · авто». Настройка: «Качество превью: Авто / фиксированное».

## 9. Без лишних проходов и копий

- **Слияние точечных операций** (§3, класс «точечный»):
  - CPU — один проход на слой: выборка с placement и crop → цепочка точечных
    операций → смешивание в цель;
  - GPU — один draw на слой с блоком параметров точечных операций (несколько
    специализированных пайплайнов, без одного гигантского шейдера).
- **Окрестностные операции** (blur, bloom, motion blur) идут через
  ping-pong-текстуры из пула. Bloom считается в пониженном разрешении.
  Промежуточные буферы нужны только им и переходам.
- **Отсечение** до декодирования (архитектура §7.3): невидимые слои, нулевые
  эффекты, выключенные эффекты.
- **Пулы**: кадры, текстуры (по формату и размеру), без выделений в
  установившемся режиме (проверяется счётчиком аллокаций в бенчмарках).
- Никаких CPU → GPU → CPU в превью. В экспорте GPU → энкодер (позже NVENC из
  текстуры).

## 10. Живой предпросмотр без изменения проекта

- `PreviewOverride` — состояние приложения, не проекта:
  `{ target, effect: AppliedEffect | ParamOverride }`.
- `SceneSource` = снимок проекта + override. Evaluator тот же. Проект, флаг
  «изменён», автосохранение и история не трогаются.
- **Наведение** на эффект в браузере — override → перерисовка текущего кадра.
  Декодированный кадр берётся из кэша, поэтому меняется только рендер.
- **Миниатюры в браузере эффектов**: текущий кадр выбранного клипа, отрисованный
  с каждым пресетом в 160×90 фоновым рендером; кэш по
  (клип, кадр, пресет, версия); отмена при уходе курсора.
- **Перетаскивание ползунка**: значения идут через override (живой отклик);
  отпускание — одна команда в историю.
- **Прямое манипулирование** (позже, в UI): ручки на превью для position,
  scale, rotation, crop, anchor и точки Point-параметров используют обратное
  преобразование `Placement` (canvas → local) из `kadr-scene`.

## 11. Undo/Redo

Новые команды `EditEngine`:
- `AddEffect { target, effect }`;
- `RemoveEffect { target, id }`;
- `UpdateEffectParams { target, id, params }`;
- `ReorderEffects`;
- `DetachEffect` (в явные дорожки);
- `SetEffectEnabled`.

- Клик в браузере — один шаг («Эффект: Cinematic Push»). Ползунок — один шаг
  на отпускание («Сила: Normal → Strong»).
- Наведение и предпросмотр — никогда не в истории.
- AI и MCP используют те же команды (метка «Claude: …»), с проверкой
  параметров по реестру.

## 12. Первый набор — 30 эффектов

Обозначения: **CPU** — нормально на процессоре; **GPU** — тяжёлая пиксельная
работа (на CPU — медленно, но корректно: эталон и экспорт); **AI** — нужна
необязательная модель.

### Motion (6)
| Эффект | Level 2 | Из чего собран | Где |
|---|---|---|---|
| Smooth Zoom | Направление (In/Out), Сила, Точка | Tween(scale) + Easing::Smooth + anchor | CPU; «на лицо» — AI (опционально) |
| Cinematic Push | Сила, Точка | Tween(scale 1→1,03…1,08) + Easing::Cinematic + MotionBlur (тонкий) | CPU; motion blur — GPU |
| Punch In | Сила, Момент | Tween(scale, 0,12 с) + Easing::Snap + MotionBlur | CPU; motion blur — GPU |
| Smooth Pan | Направление, Сила | Tween(position) + автоувеличение «без полей» + Easing::Smooth | CPU |
| Handheld | Сила | Noise1D(position, rotation) + небольшое увеличение | CPU |
| Speed Ramp | Скорость до и после, Плавность | TimeRemap + Easing; звук — без изменения высоты | CPU (декодер: произвольный доступ) |

### Transitions (6)
| Эффект | Level 2 | Из чего собран | Где |
|---|---|---|---|
| Clean Fade | Длительность, Стиль (Clean/Film) | Mix::Dissolve + Easing; Film — лёгкий подъём экспозиции в середине | CPU |
| Fade Through Color | Длительность, Цвет (чёрный/белый) | Mix::DipToColor | CPU |
| Smooth Push | Направление, Длительность | Tween(placement A и B) + Easing::Cinematic + MotionBlur (тонкий) | CPU; motion blur — GPU |
| Whip Pan | Направление | Tween(placement) + Easing::Snap + MotionBlur (сильный) | GPU |
| Zoom Through | Длительность | Tween(scale A↑, B↓→1) + Mix + MotionBlur (радиальный — из изменения масштаба) | GPU |
| Light Sweep | Направление, Цвет | Mix::Dissolve + Gradient (движущаяся полоса, Screen) | CPU |

Сознательно отложены: Camera Turn (нужна 3D-перспектива), Depth Transition и
Parallax (нужна глубина — AI), Motion Match (нужен анализ движения).

### Look (6) — один рецепт «Look», шесть пресетов, параметр — Сила
| Пресет | Из чего собран | Где |
|---|---|---|
| Cinematic | ToneCurve (мягкая S) + SplitTone (холодные тени, тёплые света) + лёгкая десатурация + Vignette | CPU |
| Warm | ColorAdjust (temperature, tint) + ToneCurve (мягкий подъём) | CPU |
| Soft Film | ToneCurve (приподнятый чёрный, мягкий «откат» светов) + Grain + Bloom (слабый) | CPU; bloom — GPU |
| Dramatic | ToneCurve (сильная S) + десатурация + Vignette | CPU |
| Vintage | ToneCurve (выцветание) + SplitTone + Grain + Vignette | CPU |
| Natural | ToneCurve (мягкий контраст) + сдержанная насыщенность | CPU |

Ручная «Коррекция» (экспозиция, контраст, насыщенность, температура) остаётся
инструментом инспектора, а не эффектом.

### Light (3)
| Эффект | Level 2 | Из чего собран | Где |
|---|---|---|---|
| Soft Glow | Сила | Bloom (порог, радиус) + Screen | GPU |
| Light Leak | Сила, Цвет, Вариант | Noise + Gradient (анимированные, низкое разрешение + апскейл) + Screen | CPU (генератор дешёвый) / GPU |
| Vignette | Сила, Мягкость | Vignette | CPU |

### Text (5) — после подпроекта титров
| Эффект | Level 2 | Из чего собран | Где |
|---|---|---|---|
| Clean Title | Текст, Шрифт, Цвет | Text + Tween(opacity, position ↑) + Easing::Cinematic | растр CPU (кэш), композиция CPU/GPU |

| Subtitle | Текст, Позиция | Text + Shape (подложка) + Tween(opacity) | как выше |

| Word Highlight | Текст, Цвет | Text + подсветка текущего слова по таймингам | как выше; тайминги из речи — AI (опционально) |

### Audio (4)
| Эффект | Level 2 | Из чего собран | Где |
|---|---|---|---|
| Fade In / Out | Длительность | огибающая громкости (уже есть) | CPU |
| Normalize | Цель (Соцсети −14 / Кино −23 LUFS) | анализ громкости EBU R128 + gain | CPU |
| Clean Voice | Сила | HPF + EQ «присутствия» + мягкий компрессор + de-esser | CPU |
| Remove Noise | Сила | спектральный шумодав (классический) или RNNoise (маленькая модель, ленивая загрузка) | CPU; AI-lite (опционально) |

## 13. Сводка: CPU, GPU, AI

- **CPU достаточно:** вычисление сцены и анимаций (всегда CPU), трансформации
  и композиция, точечные операции (Looks, Vignette, Grain), dissolve / dip /
  push / wipe / light sweep, генераторы в низком разрешении, растеризация
  текста (с кэшем), весь звук.
- **GPU предпочтителен (на CPU — корректно, но медленно):** Blur, Bloom / Soft
  Glow, MotionBlur (Cinematic Push, Punch, Whip, Zoom Through), в будущем —
  размытие фона. До появления `WgpuRenderer` они работают на CPU в
  PreviewFast; адаптивное превью держит частоту кадров.
- **AI (необязательно, ленивая загрузка):** точка «на лицо» для Zoom и Push,
  Follow Subject (трекинг), размытие фона и отделение объекта (сегментация),
  глубина (Parallax, Depth), тайминги слов (распознавание речи), RNNoise.

## 14. Чего не делаем

Графов нодов, редактора кривых уровня AE, 3D-пространства, частиц,
плагин-API, сотен переходов, LUT-библиотек «ради количества», отдельного
рендерера или шейдера на каждый эффект.
