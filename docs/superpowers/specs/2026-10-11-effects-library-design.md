## 0. Цель и границы

Пользователь выбирает клип → выбирает эффект во вкладке «Эффекты» → сразу хороший
результат → при желании 2–5 понятных параметров. «Не много эффектов, а хорошие»:
простота уровня CapCut, качество выше, нативная скорость.

**Входит (20 эффектов, 4 этапа):**

| Этап | Каркас | Эффекты |
|---|---|---|
| E1 | рецепты, `AppliedEffect`, команды с undo, вкладка «Эффекты» с живым предпросмотром и миниатюрами, секция эффектов в инспекторе, значок `fx` на клипе, анимация параметров эффектов | Движение: Плавный наезд, Кино-наезд, Резкий наезд, Плавная панорама, Ручная камера |
| E2 | примитивы рендера: тоновая кривая, split-tone, виньетка, зерно; слияние точечных операций | Looks: Кино, Тёплый, Мягкая плёнка, Драма, Винтаж, Естественный; Свет: Виньетка |
| E3 | генераторы (градиент, мягкий шум), переходы как рецепты, формат проекта 3 | Свет: Засветка; Переходы: Растворение, Через цвет, Сдвиг, Световая волна, Шторка |
| E4 | замер громкости EBU R128, звуковые цепочки, звук экспорта через Rust-микшер | Звук: Нормализация, Чистый голос, Шумоподавление |

**Не входит (заложено):** размытие, свечение (Soft Glow, свечение в «Мягкой плёнке»),
размытие движения, Whip Pan, Zoom Through — в GPU-подпроекте вместе с их CPU-эталоном;
текстовые эффекты — в подпроекте титров; Speed Ramp (кривая скорости требует работы со
звуком и произвольным доступом декодера); «точка на лицо» (нужен детектор); отвязка
рецепта в явные ключевые кадры (Detach); адаптивный регулятор качества превью (появится
с тяжёлыми эффектами или если замер E2 не уложится в бюджет); маски; импорт LUT.

## 1. Домены времени эффектов

Продолжение §1 спецификации ключевых кадров.

| Что | Домен | Поведение |
|---|---|---|
| Эффект «на весь клип» (наезд, панорама, ручная камера, Look, свет, звук) | **clip-bound**, прогресс по видимому клипу | trim и скорость растягивают/сжимают эффект на видимый клип |
| «Момент» эффекта (Резкий наезд) | **source-bound** (`SourceTime`) | держится за кадр исходника; trim его не двигает |
| Анимация параметров эффектов (ключевые кадры) | **source-bound**, как все ключи | §4 спецификации ключевых кадров |
| Переход | на склейке, длительность | как сейчас (ограничение соседними клипами) |

**Диапазон прогресса.** У `AppliedEffect` есть `progress: (from, to)`, по умолчанию
`(0, 1)`. Прогресс эффекта в момент `t`:
`p = from + (to − from) · (t − timeline_in) / duration` (целые флики → один f64).
- **Split** в точке, где прогресс равен `c`: левая половина получает `(from, c)`, правая
  `(c, to)` — **картинка на стыке не меняется** (обещание «split ничего не меняет» из
  спецификации ключевых кадров сохраняется).
- **Trim / скорость** не меняют `progress`: эффект растягивается на новый видимый клип в
  пределах своего диапазона.

## 2. Модель данных (`kadr-project`)

```rust
pub struct AppliedEffect {
    pub id: EffectId,
    pub recipe: RecipeId,                 // строка, например "smooth_zoom"
    pub version: u16,
    pub params: BTreeMap<String, ParamValue>,
    pub enabled: bool,
    pub progress: (f64, f64),            // §1, по умолчанию (0, 1)
}
pub enum ParamValue {
    Number(f64),                          // сила 0..1, длительность в секундах — по ParamDef
    Choice(String),                       // направление, пресет, цель громкости
    Point { x: f64, y: f64 },             // доля кадра, 0..1
    Color(Rgba),
    Moment(SourceTime),                   // «в момент» (Резкий наезд)
}
// Clip: effects: Vec<AppliedEffect>  (порядок = порядок применения)
// Transition: + recipe: RecipeId, version: u16, params: BTreeMap<String, ParamValue>
```

- **Прямая совместимость** (как §2.1 ключевых кадров): неизвестный рецепт или
  неизвестный вариант параметра сохраняется дословно (`serde_json::Value`), не
  вычисляется, в инспекторе — «Недоступен (создан в более новой версии)». Неизвестные
  параметры известного рецепта тоже сохраняются.
- **Версии рецептов**: заметное изменение вида — новая версия `compile`, старая
  остаётся, старые проекты выглядят как раньше.
- **Сила** — `Number` в `[0, 1]` (UI 0–100 %). Множитель интенсивности `k = s / 0.6`:
  «Обычно» (60 %) — пресет как задуман, 0 % — эффекта нет, 100 % — ×1,67. Отметки
  «Мягко / Обычно / Сильно» на 30 / 60 / 90 %, ползунок к ним притягивается.
- **Один экземпляр рецепта на клип.** `AddEffect` рецепта, который уже есть, заменяет
  его параметры (Look «Тёплый» поверх Look «Кино» — замена, а не второй Look).
- **Анимация параметров эффектов**: `AnimParam` получает вариант
  `Effect { effect: EffectId, key: ParamKey }`, в JSON — ключ `"fx:<effect-id>:<key>"`;
  анимируются только `Number`-параметры. Значение из дорожки заменяет статическое
  (§3.2 ключевых кадров). Удаление эффекта удаляет его дорожки (одна запись undo).
  Сохранение неизвестных ключей работает как раньше.
- **Формат проекта 3.** `FORMAT_VERSION` 2 → 3: иначе старая сборка молча потеряет
  эффекты и рецепты переходов. `migrate(value, 2)`:
  - старое поле `effects: [{id, kind, enabled, params}]` (никогда не вычислялось) —
    каждый элемент становится `AppliedEffect` с `recipe = kind` (неизвестный рецепт —
    сохраняется как есть);
  - `Transition.kind` → рецепт: `cross_dissolve` → `clean_fade {style: clean}`,
    `dip_to_black` → `fade_through_color {color: black}`, `wipe` → `wipe {direction:
    left, softness: 0}`; длительность и положение без изменений; старое поле больше
    не пишется.

## 3. Реестр и вычисление (`kadr-effects`)

Новый crate, зависит от `kadr-core`, `kadr-scene`, `kadr-project`; им пользуется
evaluator в `kadr-timeline`.

```rust
pub struct RecipeDef {
    pub id: &'static str,
    pub category: Category,          // Motion | Look | Light | Transition | Audio
    pub target: Target,              // Clip | Cut | AudioClip
    pub version: u16,
    pub params: &'static [ParamDef], // 0–5 параметров
    pub cost: CostClass,             // Cheap | Medium (Heavy — в GPU-подпроекте)
    pub compile: fn(&Params, &CompileCtx) -> Compiled,
}
pub struct CompileCtx { pub progress: f64, pub source_time: SourceTime, pub clip_secs: f64,
                        pub canvas: SizeU, pub frame: Time, pub seed: u64 }
pub struct Compiled { pub placement: PlacementDelta, pub effects: Vec<Effect>,
                      pub overlays: Vec<Layer>, pub transition: Option<TransitionBuild>,
                      pub audio: Vec<AudioOp> }
```

- **Кривые** (`kadr-core::ease`): к пяти существующим добавляются `Cinematic`
  (cubic-bezier 0.45, 0, 0.2, 1), `Snap` (expo-out: `1 − 2^(−10u)`, нормированная к 1),
  `Gentle` (sine in-out). Формулы — сохраняемая семантика, закреплены тестами по точкам.
- **Шум** `Noise1D { seed, frequency, amplitude }` — гладкий value-noise с
  детерминированным целочисленным хэшем (PCG32), одинаковый на CPU и будущем GPU.
- **Пресеты Looks** — данные: `crates/effects/looks.json` (точки кривой, split-tone,
  виньетка, зерно, коррекция). Добавить Look = добавить запись, без кода.
- **Evaluator** (`kadr-timeline::scene`): после `clip_state_at` для каждого включённого
  эффекта клипа в порядке списка: прогресс по §1 → `compile` → `PlacementDelta`
  умножается поверх `Placement` клипа (масштаб вокруг якоря, сдвиг, поворот);
  цветовые примитивы добавляются **после** коррекции инспектора (сначала коррекция,
  потом Look); оверлеи (засветка) — отдельные слои над клипом с режимом Screen.
  Значение параметра в момент `t` — дорожка `fx:` (если есть) или статическое.
  Сила 0 или выключенный эффект — нет ни примитивов, ни оверлея (отсечение).
- **Неизвестный рецепт** в evaluator пропускается.

## 4. Примитивы рендера (`kadr-scene`, `kadr-render`)

Новые варианты `scene::Effect` и генераторы; формулы — §3 черновика (принимаются):

| Примитив | Параметры | Реализация CPU |
|---|---|---|
| `ToneCurve` | до 5 точек (общая или по каналам) → монотонный сплайн Fritsch–Carlson → таблица 256 | точечный |
| `SplitTone` | оттенок и сила для теней и светов, баланс | точечный |
| `Vignette` | amount, midpoint, feather (круг в пикселях холста, aspect-correct) | точечный |
| `Grain` | amount, size, seed (PCG32 по (x, y, кадр, seed)) | точечный |
| `Gradient` (генератор) | linear / radial, 2–3 цвета, позиция | слой-генератор |
| `Noise` (генератор) | частота, seed, время; низкое разрешение + билинейный апскейл | слой-генератор |

- **Слияние точечных операций**: коррекция → кривая → split-tone → виньетка → зерно за
  **один проход по пикселям** слоя (выборка с placement/crop → цепочка → смешивание в
  цель), ограничение в [0, 1] один раз в конце, без промежуточных буферов.
- **Переходы**: `TransitionLayer` получает возможность двигать `Placement` сторон
  (для «Сдвига»); «Световая волна» — `Dissolve` + движущаяся полоса `Gradient` в Screen.
- Каждому примитиву — эталонный PNG-тест и тест «нейтральные параметры = тождество».

## 5. Эффекты

`k` — множитель силы (§2). «Точка» по умолчанию — центр кадра; «Момент» по умолчанию —
кадр исходника под плейхедом при применении.

**Движение** (все — CPU; автоувеличение «без полей» там, где кадр сдвигается)

| Эффект | Параметры | Сборка (при `k = 1`) |
|---|---|---|
| Плавный наезд / Smooth Zoom | Направление (В/Из), Сила, Точка | масштаб 1,00 → 1,10 вокруг точки, кривая Smooth, на весь прогресс |
| Кино-наезд / Cinematic Push | Сила, Точка | масштаб 1,00 → 1,05 вокруг точки, кривая Cinematic |
| Резкий наезд / Punch In | Сила, Момент, Точка | в момент: 1,00 → 1,15 за 0,12 с, кривая Snap, держится до конца клипа |
| Плавная панорама / Smooth Pan | Направление (← → ↑ ↓), Сила | сдвиг на 6 % кадра, масштаб 1,06 (без полей), кривая Smooth |
| Ручная камера / Handheld | Сила | `Noise1D` по x, y (0,6 % кадра) и повороту (0,4°), ~0,7 Гц, масштаб «без полей», seed — от id эффекта |

**Looks** — один рецепт `look`, параметры: Пресет, Сила. Интерполяция от нейтральных
значений к пресету с множителем `k`.

| Пресет | Состав (начальные значения уточняются по эталонам и одобряются владельцем) |
|---|---|
| Кино / Cinematic | мягкая S-кривая, холодные тени + тёплые света, насыщенность −10 %, виньетка 0,25 |
| Тёплый / Warm | температура +0,25, tint +0,05, мягкий подъём середины |
| Мягкая плёнка / Soft Film | приподнятый чёрный (0,06), мягкий «откат» светов, зерно 0,04 |
| Драма / Dramatic | сильная S-кривая, насыщенность −25 %, виньетка 0,4 |
| Винтаж / Vintage | выцветание (чёрный 0,1, белый 0,92), тёплые тени, зерно 0,05, виньетка 0,3 |
| Естественный / Natural | мягкий контраст, насыщенность −5 % |

**Свет**

| Эффект | Параметры | Сборка |
|---|---|---|
| Виньетка / Vignette | Сила, Мягкость | `Vignette` |
| Засветка / Light Leak | Сила, Цвет (тёплый / розовый / холодный), Вариант (1–3) | оверлей: `Noise` + `Gradient`, медленный дрейф по прогрессу, Screen |

**Переходы** (цель — склейка; параметр «Длительность» у всех, по умолчанию 0,5 с)

| Эффект | Параметры | Сборка |
|---|---|---|
| Растворение / Clean Fade | Длительность, Стиль (Чистый / Плёнка) | `Dissolve`; «Плёнка» — лёгкий подъём экспозиции в середине |
| Через цвет / Fade Through Color | Длительность, Цвет (чёрный / белый) | `DipToColor` |
| Сдвиг / Smooth Push | Длительность, Направление | сдвиг placement обеих сторон, кривая Cinematic |
| Световая волна / Light Sweep | Длительность, Направление, Цвет | `Dissolve` + движущаяся полоса `Gradient` (Screen) |
| Шторка / Wipe | Длительность, Направление, Мягкость | существующий `Wipe` |

**Звук** — §8.

## 6. Интерфейс

### 6.1 Вкладка «Эффекты» (рядом с «Медиа», левая панель)
- Фильтры: Все · Движение · Looks · Свет · Переходы · Звук; поиск по названию (RU/EN).
- Сетка карточек 160×90. Миниатюра — текущий кадр выделенного клипа с эффектом при силе
  «Обычно» (фоновый рендер, кэш по (клип, кадр, рецепт, пресет, версия), отмена при
  уходе); у движения при наведении миниатюра проигрывает движение коротким циклом.
  Без выделенного клипа — общий пример и подсказка «Выделите клип, чтобы примерить
  эффекты на нём». У переходов — схематичная анимация, у звука — иконка.
- **Наведение** (≥ 150 мс) — живой предпросмотр на превью в кадре под плейхедом;
  уход — как было. Проект, история, «изменён», автосохранение не трогаются: подмена
  живёт в состоянии приложения (`PreviewOverride`), декодированный кадр — из кэша.
- **Клик** — применить к выделенным клипам (одна запись undo «Эффект: Плавный наезд»);
  **перетаскивание** — на клип таймлайна. Неподходящая цель (звуковой эффект на
  видеоклип и наоборот) — карточка неактивна с подсказкой, бросок отклоняется.
- **Переходы**: перетаскивание на склейку (склейка подсвечивается) или клик — к склейке,
  ближайшей к плейхеду, на дорожке выделенного клипа; нет склейки — подсказка.

### 6.2 Инспектор (одобренный макет A)
- Секция «Эффекты клипа» под коррекцией: на эффект — заголовок (переключатель, название,
  меню `⋯`: Сбросить, Удалить, Выше, Ниже) и 2–5 параметров:
  - Сила — ползунок 0–100 % с отметками и притяжением, `◀ ◆ ▶`;
  - Направление / Стиль / Пресет / Цель — сегменты или выпадающий список;
  - Точка — «щёлкните на превью»: режим выбора (курсор-прицел, Esc — отмена); пока
    эффект в фокусе, на превью видна метка точки;
  - Момент — время с кнопкой «к плейхеду».
- Числовые параметры анимируются тем же механизмом, что трансформация (правила
  «кадр в плейхеде», «плейхед вне клипа», одна запись undo на жест).
- Выделенный на таймлайне переход показывает свои параметры. «Нормализация» показывает
  замер: «−19,2 LUFS → −14».
- «Сброс» секции эффектов — удалить все эффекты клипа одним шагом undo (с подтверждением).

### 6.3 Таймлайн
- Значок `fx N` в заголовке клипа; подсказка при наведении перечисляет эффекты.
- Переходы на склейках — как сейчас, с названием рецепта.

### 6.4 Названия (RU / EN, через каталоги)

Punch In · Плавная панорама / Smooth Pan · Ручная камера / Handheld. Looks: Кино /

## 7. Команды, MCP, AI

**`EditEngine`** (все с undo, параметры проверяются по реестру — диапазоны, варианты):

| Команда | Источник |
|---|---|
| `AddEffect { clip, effect }` | клик/бросок карточки; рецепт уже есть — замена его параметров |
| `RemoveEffect { clip, id }` | меню `⋯`; удаляет и дорожки `fx:` эффекта |
| `UpdateEffect { clip, id, params?, enabled? }` | параметры, переключатель; ползунок — через `LiveEdit`, одна запись при отпускании |
| `MoveEffect { clip, id, to }` | Выше / Ниже |
| `SetTransition { track, at, recipe, params, duration }` | заменяет `AddTransition` (старая форма понимается) |

Применение к нескольким клипам — одна запись undo. Неизвестный рецепт добавить нельзя,
только сохранить. Записи без изменений не создаются (проверка «ничего не изменилось»
у вызывающего, как в подпроекте ключевых кадров).

**MCP**: `list_effects` (реестр: id, категория, цель, параметры с типами, диапазонами и
вариантами); операции `edit`: `add_effect {clip_id, recipe, params?}`, `remove_effect`,
`set_effect {clip_id, effect_id, params?, enabled?}`, `move_effect`; `add_transition`
получает `recipe` и `params` (`kind` — синоним); анимация параметров эффектов — через
`set_keyframe` и др. с `param: "fx:<effect-id>:<key>"`; `get_state` показывает эффекты
клипа и рецепты переходов.

**AI-ассистент**: `AiCommand` получает `AddEffect` / `SetEffect` / `RemoveEffect`
(закрытый язык команд, проверка по реестру, тот же шлюз стоимости и приватности).
Изменение статического значения анимированного параметра эффекта отклоняется с
понятной причиной (как R24 ключевых кадров).

## 8. Звук (этап E4)

- **Звук экспорта — через Rust-микшер** (как видео в M5): экспорт отдаёт FFmpeg готовый
  PCM вместо цепочки `volume/pan/afade/amix`. Одна реализация — «как в превью, так и в
  файле» по построению; тест: PCM превью и экспорта совпадают побайтно.
- **Нормализация** (цель: Соцсети −14 / Кино −23 LUFS): интегральная громкость EBU R128
  (BS.1770: K-фильтр, гейтинг −70 LUFS абсолютный и −10 LU относительный) по видимому
  диапазону клипа — фоновая задача с кэшем (asset, диапазон); после trim — пересчёт.
  Усиление = цель − замер, но не выше пика −1 dBFS (sample peak); при ограничении
  инспектор пишет причину. Пока замер не готов — эффект не меняет звук и это видно.
- **Чистый голос** (Сила): срез низа 80 Гц, подъём «присутствия» 3–5 кГц (+3 dB при
  `k = 1`), компрессор 3:1 с мягким коленом, де-эссер 6–8 кГц; сила масштабирует всё.
- **Шумоподавление** (Сила): спектральное (STFT, окно Ханна 2048, перекрытие 75 %),
  профиль шума — медиана самых тихих 10 % окон клипа, подавление с плавными
  коэффициентами (без «музыкального шума»); сила — глубина подавления.
- Звуковые эффекты стоят в цепочке клипа до gain/pan/fade (громкость клипа —
  последняя).

## 9. Тесты и приёмка

| Уровень | Что проверяем |
|---|---|
| `ease` | новые кривые по контрольным точкам; монотонность; 0 → 0, 1 → 1 |
| модель | serde round-trip; неизвестный рецепт/вариант/параметр переживает load → save; миграция формата 2 → 3 (старые `effects`, три перехода); `TooNew` |
| evaluator | сила 0 / выключен = кадр без эффекта (попиксельно); split не меняет картинку (свойство, как в ключевых кадрах); trim растягивает эффект на видимый клип; «момент» держится за исходник; дорожки `fx:` |
| рендер | эталонный PNG на каждый примитив и каждый Look; нейтральные параметры = тождество; один проход точечных операций (счётчик проходов/аллокаций) |
| команды | каждая команда §7 и undo; замена одноимённого рецепта; удаление с дорожками; жест = одна запись |
| звук | замер LUFS на эталонных сигналах EBU Tech 3341 (допуск ±0,1 LU); PCM превью = PCM экспорта; нейтральная сила = тождество |
| производительность | `kadr-bench`: Look + движение на 1080p — время кадра в бюджете на CPU; стоимость предпросмотра при наведении; миниатюры не мешают воспроизведению |

**Живая приёмка через `kadr-mcp`** (реальные клипы владельца, RU и EN, большое и
маленькое окно): наведение показывает эффект мгновенно и возвращает без следов;
применение — одна запись undo; Looks выглядят «дорого» на реальном материале; наезд
плавный; split и trim ведут себя по §1; переход ставится на склейку перетаскиванием;
нормализация даёт заявленную громкость в экспорте.

## 10. Порядок реализации (для плана)

1. E1: `kadr-effects` (реестр, кривые, шум), модель `AppliedEffect` + формат 3 + миграция
   старых `effects`, evaluator (движение), команды, вкладка «Эффекты», инспектор,
   `fx` на таймлайне, `fx:`-анимация, MCP/AI для эффектов.
2. E2: примитивы цвета + слияние, Looks, Виньетка, эталоны, замер производительности.
3. E3: генераторы, Засветка, переходы-рецепты + миграция переходов, `SetTransition`.
4. E4: звук экспорта через Rust-микшер, R128, три звуковых эффекта.
5. Бенчмарки, живая приёмка, ревью Opus.
