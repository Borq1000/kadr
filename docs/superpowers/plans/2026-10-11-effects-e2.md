# Effects Library — Stage E2 (Looks + Vignette) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Six polished Looks (Кино, Тёплый, Мягкая плёнка, Драма, Винтаж, Естественный) and a Vignette in the «Эффекты» tab — every Look preset its own card with a live thumbnail, hover to try it on the selected clips, click or drag to apply, a preset list and Сила in the inspector — rendered by four new colour primitives (tone curve, split-tone, vignette, grain) fused with the colour correction into one pass per layer and matched by the reference renderer within ±1 LSB.

**Architecture:** `kadr-core::hash` takes the PCG32 hash over from `kadr-effects` (saved semantics, now shared with the renderer). `kadr-scene` gains `Effect::{ToneCurve, SplitTone, Vignette, Grain}` as plain data plus the normative pure helpers both renderers use (the 256-entry Fritsch–Carlson table, the hue offset, the vignette distance and gain, the grain cell hash) and the contract text. `kadr-render`'s CPU renderer replaces the affine-only `ColorFx` with a fused point chain (adjusts folded into one affine, then the other primitives in list order, one clamp, the canvas position only for spatial ones) and counts passes; the test reference implements the same rules in f64. `kadr-effects` gets the `look` recipe (presets from `crates/effects/looks.json`) and `vignette`; the evaluator (`kadr-timeline::fx`) keeps the compiled colour primitives and `clip_layer` appends them after the inspector's correction. The editor shows one card per Look preset (`look:<preset>`), a dropdown for the preset, a scrolling chip row; MCP and the AI assistant reach the recipes through the registry.

**Tech Stack:** Rust 2024 workspace, `serde` / `serde_json`, `rayon` (CPU renderer), Slint 1.18.1 (`apps/editor/ui/*.slint`), `kadr-i18n` JSON catalogs, `png` (golden images), `cargo test` / `cargo clippy` on Windows (Git Bash).

## Global Constraints

- Colour work happens on **unpremultiplied non-linear Rec.709** values: `rgb / a` → the layer's primitives **in list order** → clamp to [0, 1] **once, at the end** → `× a`; a sample with `a = 0` is left as it is; a chain whose every primitive is neutral is skipped entirely, its clamp too (`Effect::is_neutral`). The only clamp inside a chain is the tone curve's input clamp to its domain [0, 1] (documented exception, D1).
- Formulas (D1, exact): **ToneCurve** — master curve on R′, G′, B′; 2–5 points `(x, y)` in [0, 1], x strictly increasing, y non-decreasing; Fritsch–Carlson monotone cubic → 256 f32 entries at `x = i/255`; lookup `x = clamp(v, 0, 1)·255`, linear between neighbours; identity points → identity. **SplitTone** — `Y = luma709(c)`, `Yb = clamp(Y + 0.25·balance, 0, 1)`, `ws = (1 − Yb)²`, `wh = Yb²`, `d(h) = hsv(h, 1, 1) − luma709(hsv(h, 1, 1))·(1, 1, 1)`, `c′ = c + shadow_amount·ws·d(sh) + highlight_amount·wh·d(hh)`; neutral when both amounts are 0. **Vignette** — `d` = distance of the canvas-pixel centre from the canvas centre ÷ half the canvas diagonal (a circle in canvas pixels, corners `d = 1`), `v = 1 − amount·smoothstep(midpoint, midpoint + max(feather, 0.01), d)`, `c′ = c·v`; canvas space, not the clip's picture; neutral when `amount = 0`. **Grain** — cell `(floor(cx/size), floor(cy/size))` in canvas pixels (size ≥ 1), `h = pcg32_hash(seed, (cell_y as u64) << 32 | cell_x as u32 as u64) / u32::MAX`, `w(Y) = 4·Y·(1 − Y)`, `c′ = c + (h − 0.5)·amount·w(Y)` on all three channels; the recipe's seed is `effect_seed ^ fmix64(frame.flicks)`; neutral when `amount = 0`.
- Exposure stays `c · 2^(ev/2.4)` (pure 2.4 power), contrast about 0.5, temperature `R·(1 + 0.1t)`, `B·(1 − 0.1t)`, tint `G·(1 − 0.05u)`, saturation about Rec.709 luma `Y = 0.2126R + 0.7152G + 0.0722B` — unchanged from E1.
- **One pass per layer** (spec §4): sample (placement, crop) → the fused chain → opacity and coverage → composite, with no intermediate buffer; consecutive `ColorAdjust`s fold into one affine; spatial primitives read the canvas position of the output pixel centre `((x − o.x)/k, (y − o.y)/k)`, computed only when the chain has one. A layer with a full Look draws in exactly one pass and allocates no pool buffer (`RenderStats::passes`, `CpuRenderer::pool_allocations`).
- Order in a layer's `effects` (spec §3): the inspector's `ColorAdjust` first (when not neutral), then each enabled, known effect's primitives in the clip's list order. A Look emits `ColorAdjust → ToneCurve → SplitTone → Vignette → Grain`, dropping neutral ones; strength 0 or a switched-off effect emits nothing (no `compile` at all).
- Strength (spec §2): `Number` in [0, 1], `k = s / 0.6` (`kadr_effects::intensity`); every numeric preset value moves from its neutral by `k` (curve `y = x + k·(y_p − x)` clamped into [0, 1] then made non-decreasing; correction values from `ColorAdjust::NEUTRAL`; amounts × k). Vignette at `k = 1`: amount 0.35, midpoint 0.45, feather `0.15 + 0.7·softness`.
- Presets are data: `crates/effects/looks.json`, compiled in with `include_str!`; adding a Look = adding a record plus its two catalog names, no code (spec §3). Their numbers start from spec §5's table and are tuned with the owner at live acceptance — they live in `looks.json` only.
- One instance of a recipe per clip (spec §2): `AddEffect` of a recipe the clip has replaces it in place (same id and position, new parameters, its `fx:` tracks dropped) — a second Look card replaces the Look.
- Saved semantics are never changed: `pcg32_hash` / `fmix64` keep their pinned values when they move to `kadr_core::hash`; recipe versions stay 1.
- `kadr-render` depends on `kadr-scene` and `kadr-core` only; `kadr-effects` is a **dev-dependency** of `kadr-render` (golden images of the Looks), never a normal one.
- CPU / reference parity: every byte within ±1 LSB (one more at a pixel where the reference stored a value within 1e-3 LSB of a rounding tie). ## Spec refinements (decided here; report them to the owner)

1. **Card variants.** `RecipeDef.variants: Option<&'static str>` names the `Choice` parameter whose options are a recipe's variants (the Look's `preset`). Each variant is its own card, id `<recipe>:<variant>` (`look:warm`), name `fx.<recipe>.<variant>` (`fx.look.warm`) — one source of names for the card, the inspector's list and the block title (D5, D7). Other choices keep `fx.choice.<option>`.
2. **The Look's options come from `looks.json`.** The `preset` options are the JSON's keys in file order (the registry becomes a `LazyLock`), so a new Look needs no code; the six spec presets are pinned by a test.
3. **A preset this build lacks** (a newer Kadr's Look) makes the effect "from a newer Kadr": `kadr_effects::definition` returns `None` — it is not rendered (not silently replaced by the default preset), shown «Недоступен», kept verbatim, only moved or removed. A missing `preset` value means the default (Кино).
4. **Names.** An effect with a variant is named «Look · Кино» (`fx.variant_named`, EN «Look · Cinematic») in the inspector header, the `fx N` tooltip and history labels; applying a card is labelled with the card's own name («Эффект: Кино»).
5. **A second Look card replaces the whole Look** (spec §2 «замена его параметров»): preset and strength (back to «Обычно»), its `fx:` keyframes dropped. The inspector's preset list changes the preset only (strength and keyframes stay). «Сбросить» of a Look keeps its preset, as it keeps a moment (E1 ruling R13).
6. **Grain** cells are `2 × canvas.h / 1080` canvas pixels, at least 1 (`GRAIN_CELL_PER_1080`); the grain changes every frame (`seed ^ fmix64(frame flicks)`), holds while paused and is identical on both halves of a split.
7. **A Look's vignette** has the Vignette effect's shape at softness 0.5 (midpoint 0.45, feather 0.5); both are canvas-space: on a picture-in-picture clip the darkening follows the canvas (the PiP is darkened by where it sits).
8. **Curve robustness.** A renderer uses `ToneCurve::usable()`: non-finite points dropped, the rest clamped into [0, 1], sorted by x (of equal x the first given), y made non-decreasing; fewer than two left → identity; constant below the first and above the last point. A curve is neutral only when its usable points run (0, 0) … (1, 1) on the diagonal.
9. **Inspector.** The variant `Choice` renders as a dropdown (`FxParamRow.kind = 4`, the app's own popup list with a check on the current one); icon choices stay segments. A `0..1` `Number` other than strength (Мягкость) shows as 0–100 %.
10. **`RenderStats::passes`** counts per-pixel passes: one per layer drawn (sampled or copied by a fast path, top level or inside a transition) and one per transition mix; a layer's effects add none.
11. **Cost model** weights per covered pixel (relative to one bilinear sample + blend = 1): ColorAdjust 0.5 (unchanged), ToneCurve 0.3, SplitTone 0.3, Vignette 0.4, Grain 0.6, neutral 0. A full-frame layer with a full Look is `Medium`. Task 9 compares them with the bench.
12. **Chips** become a horizontal `Flickable`; a vertical wheel, which Slint's `Flickable` ignores when it cannot scroll vertically, falls through to a `TouchArea` beneath that scrolls sideways; a fade marks each side with more chips.
13. **MCP `list_effects`** gives a variant recipe a `variants` list (`key` and the ru / en name of each preset).
14. **Vignette** has «Сила» and «Мягкость» (`softness`, `Number` 0..1, default 0.5, animatable like any number).

```rust
//! Integer hashes with saved semantics (effects spec §3: «детерминированный
//! целочисленный хэш (PCG32), одинаковый на CPU и будущем GPU»): u64
//! wrapping operations only, so a shader reproduces them bit for bit. A
//! project's handheld shake (`kadr_effects::Noise1D`) and grain
//! (`kadr_scene::Grain`) are made of them: never change one.

/// Odd 64-bit golden-ratio constant (splitmix64's increment).
pub const GOLDEN: u64 = 0x9E37_79B9_7F4A_7C15;

/// murmur3's `fmix64` finaliser: a bijection on `u64` that avalanches every
/// input bit into every output bit (0 is its fixed point).
pub fn fmix64(mut x: u64) -> u64 {
    x ^= x >> 33;
    x = x.wrapping_mul(0xFF51_AFD7_ED55_8CCD);
    x ^= x >> 33;
    x = x.wrapping_mul(0xC4CE_B9FE_1A85_EC53);
    x ^ (x >> 33)
}

/// The hash of index `i` on stream `seed`:
///
/// 1. `stream = fmix64(seed + GOLDEN mod 2⁶⁴)` ([`pcg32_stream`]) — all 64
///    seed bits avalanched (the offset keeps seed 0 off `fmix64`'s fixed point);
/// 2. `state = fmix64(stream ^ (i · GOLDEN mod 2⁶⁴))`;
/// 3. the PCG32 XSH-RR output of `state`:
///    `rotr32(((state >> 18) ^ state) >> 27 truncated to 32 bits, state >> 59)`.
///
/// Different seeds give unrelated sequences, never shifted copies.
pub fn pcg32_hash(seed: u64, i: u64) -> u32 {
    pcg32_at(pcg32_stream(seed), i)
}

/// Step 1 of [`pcg32_hash`], once per seed (a renderer hashing every pixel of a layer).
pub fn pcg32_stream(seed: u64) -> u64 {
    fmix64(seed.wrapping_add(GOLDEN))
}

/// Steps 2 and 3 of [`pcg32_hash`] on a [`pcg32_stream`].
pub fn pcg32_at(stream: u64, i: u64) -> u32 {
    let state = fmix64(stream ^ i.wrapping_mul(GOLDEN));
    let xorshifted = (((state >> 18) ^ state) >> 27) as u32;
    xorshifted.rotate_right((state >> 59) as u32)
}
```

```rust
//! The colour primitives of effects E2 (effects spec §4; formulas: the
//! effects system draft §3 «Примитивы цвета», exact rules in the crate docs,
//! "Point operations"): plain data, plus the normative pure helpers every
//! renderer uses — the CPU renderer now, a GPU one later (the tone table
//! becomes its 1D texture, the grain hash its integer shader code).

/// Rec.709 luma weights of non-linear R'G'B'.
pub const LUMA709: [f64; 3] = [0.2126, 0.7152, 0.0722];

/// `Y(c)`: the Rec.709 luma of non-linear R'G'B'.
pub fn luma709(c: [f64; 3]) -> f64 {
    LUMA709[0] * c[0] + LUMA709[1] * c[1] + LUMA709[2] * c[2]
}

/// `t²·(3 − 2t)` with `t = clamp((x − e0) / (e1 − e0), 0, 1)`; `e1 > e0`.
pub fn smoothstep(e0: f64, e1: f64, x: f64) -> f64 {
    let t = ((x - e0) / (e1 - e0)).clamp(0.0, 1.0);
    t * t * (3.0 - 2.0 * t)
}

/// One tone curve for R', G' and B' (E2 has no per-channel curves, D11).
#[derive(Clone, Debug, PartialEq)]
pub struct ToneCurve {
    /// 2–5 control points `(x, y)` in [0, 1], x strictly increasing, y
    /// non-decreasing; anything else is cleaned up by [`ToneCurve::usable`].
    pub points: Vec<(f32, f32)>,
}

impl ToneCurve {
    pub fn identity() -> ToneCurve {
        ToneCurve { points: vec![(0.0, 0.0), (1.0, 1.0)] }
    }

    /// The points the curve uses (refinement 8): non-finite ones dropped,
    /// the rest clamped into [0, 1] and sorted by x; of points sharing an x
    /// the first given; each y at least the one before. Fewer than two left:
    /// the identity's two.
    pub fn usable(&self) -> Vec<(f64, f64)> {
        let mut p: Vec<(f64, f64)> = self
            .points
            .iter()
            .filter(|(x, y)| x.is_finite() && y.is_finite())
            .map(|&(x, y)| ((x as f64).clamp(0.0, 1.0), (y as f64).clamp(0.0, 1.0)))
            .collect();
        p.sort_by(|a, b| a.0.total_cmp(&b.0));
        p.dedup_by(|later, earlier| later.0 == earlier.0);
        for i in 1..p.len() {
            p[i].1 = p[i].1.max(p[i - 1].1);
        }
        if p.len() < 2 { vec![(0.0, 0.0), (1.0, 1.0)] } else { p }
    }

    /// Whether the curve maps every value to itself: its usable points run
    /// from (0, 0) to (1, 1) on the diagonal (the curve is constant beyond
    /// its first and last points, so one that starts later is not).
    pub fn is_neutral(&self) -> bool {
        let p = self.usable();
        p.first() == Some(&(0.0, 0.0)) && p.last() == Some(&(1.0, 1.0)) && p.iter().all(|(x, y)| x == y)
    }

    /// The normative 256-entry table: the monotone cubic Hermite spline of
    /// Fritsch and Carlson through [`ToneCurve::usable`], evaluated in f64 at
    /// `x = i/255` and stored as f32. Secants `d_k`; tangents `m_0 = d_0`,
    /// `m_{n−1} = d_{n−2}`, inside `m_k = 0` where `d_{k−1}·d_k ≤ 0`, else
    /// `(d_{k−1} + d_k)/2`; then for `k = 0 … n−2` in order: `d_k = 0` sets
    /// `m_k = m_{k+1} = 0`, else with `α = m_k/d_k`, `β = m_{k+1}/d_k`,
    /// `α² + β² > 9` scales both by `3/√(α² + β²)`. Below the first point the
    /// curve is its y, above the last point the last y.
    pub fn table(&self) -> [f32; 256] {
        let p = self.usable();
        let n = p.len();
        let d: Vec<f64> = (0..n - 1).map(|k| (p[k + 1].1 - p[k].1) / (p[k + 1].0 - p[k].0)).collect();
        let mut m = vec![0.0; n];
        m[0] = d[0];
        m[n - 1] = d[n - 2];
        for k in 1..n - 1 {
            m[k] = if d[k - 1] * d[k] <= 0.0 { 0.0 } else { (d[k - 1] + d[k]) / 2.0 };
        }
        for k in 0..n - 1 {
            if d[k] == 0.0 {
                m[k] = 0.0;
                m[k + 1] = 0.0;
            } else {
                let (a, b) = (m[k] / d[k], m[k + 1] / d[k]);
                let s = a * a + b * b;
                if s > 9.0 {
                    let tau = 3.0 / s.sqrt();
                    m[k] = tau * a * d[k];
                    m[k + 1] = tau * b * d[k];
                }
            }
        }
        std::array::from_fn(|i| {
            let x = i as f64 / 255.0;
            let v = if x <= p[0].0 {
                p[0].1
            } else if x >= p[n - 1].0 {
                p[n - 1].1
            } else {
                let k = (0..n - 1).find(|&k| x < p[k + 1].0).unwrap_or(n - 2);
                let h = p[k + 1].0 - p[k].0;
                let t = (x - p[k].0) / h;
                let (t2, t3) = (t * t, t * t * t);
                (2.0 * t3 - 3.0 * t2 + 1.0) * p[k].1 + (t3 - 2.0 * t2 + t) * h * m[k] + (-2.0 * t3 + 3.0 * t2) * p[k + 1].1 + (t3 - t2) * h * m[k + 1]
            };
            v.clamp(0.0, 1.0) as f32
        })
    }
}

/// One channel through a tone table: `v` clamped into [0, 1] — the
/// curve's domain, the one clamp inside a chain — `× 255`, then linear
/// between the two neighbouring entries. NaN reads as 0.
#[inline]
pub fn tone_lookup(table: &[f32; 256], v: f32) -> f32 {
    let x = if v.is_nan() { 0.0 } else { v.clamp(0.0, 1.0) } * 255.0;
    let i = (x as usize).min(254);
    table[i] + (table[i + 1] - table[i]) * (x - i as f32)
}

/// `d(h)` of the split tone: the hue `h` (degrees, taken mod 360) at full
/// saturation and value, `hsv(h, 1, 1)`, minus its own Rec.709 luma — a
/// pure chroma shift.
pub fn hue_offset(hue_deg: f64) -> [f64; 3] {
    let h = hue_deg.rem_euclid(360.0) / 60.0;
    let x = 1.0 - (h % 2.0 - 1.0).abs();
    let rgb = match h as u32 {
        0 => [1.0, x, 0.0],
        1 => [x, 1.0, 0.0],
        2 => [0.0, 1.0, x],
        3 => [0.0, x, 1.0],
        4 => [x, 0.0, 1.0],
        _ => [1.0, 0.0, x],
    };
    let y = luma709(rgb);
    rgb.map(|v| v - y)
}

/// Darkens towards the canvas corners: a circle in canvas pixels.
#[derive(Clone, Copy, Debug, PartialEq)]
pub struct Vignette {
    /// 0..1: the darkening at full distance.
    pub amount: f32,
    /// Where the darkening starts, as a [`Vignette::distance`].
    pub midpoint: f32,
    /// Width of the soft edge in distance units (at least 0.01).
    pub feather: f32,
}

impl Vignette {
    pub fn is_neutral(&self) -> bool {
        self.amount == 0.0
    }

    /// `d` of canvas point `(x, y)`: its distance from the canvas centre ÷
    /// half the canvas diagonal — 0 in the centre, 1 in the corners.
    pub fn distance(canvas_w: f64, canvas_h: f64, x: f64, y: f64) -> f64 {
        let (dx, dy) = (x - canvas_w / 2.0, y - canvas_h / 2.0);
        (dx * dx + dy * dy).sqrt() / ((canvas_w * canvas_w + canvas_h * canvas_h).sqrt() / 2.0)
    }

    /// `v = 1 − amount · smoothstep(midpoint, midpoint + max(feather, 0.01), d)`.
    pub fn gain(&self, d: f64) -> f64 {
        let e0 = self.midpoint as f64;
        1.0 - self.amount as f64 * smoothstep(e0, e0 + (self.feather as f64).max(0.01), d)
    }
}

    pub amount: f32,
    /// Side of a grain cell in canvas pixels.
    pub size: f32,
    /// The recipe varies it per frame.

}

impl Grain {
    pub fn is_neutral(&self) -> bool {
        self.amount == 0.0
    }

    /// The cell side in canvas pixels: `size`, but at least 1 (a size below
    /// 1 or not finite counts as 1).
    pub fn cell_size(&self) -> f64 {
        let s = self.size as f64;
        if s.is_finite() && s >= 1.0 { s } else { 1.0 }
    }

    /// The hash index of the cell of side `size` holding canvas point
    /// `(x, y)`: `floor(y/size) << 32 | floor(x/size)`, each taken as 32 bits.
    #[inline]
    pub fn cell_index(size: f64, x: f64, y: f64) -> u64 {
        // Truncation is floor for q ≥ 0 — the whole canvas — and needs no libm call.
        let cell = |v: f64| {
            let q = v / size;
            (if q >= 0.0 { q as i64 } else { q.floor() as i64 }) as u32 as u64
        };
        (cell(y) << 32) | cell(x)
    }

    /// `h` of canvas point `(x, y)`: `pcg32_hash(seed, cell index) / (2³² − 1)`, in [0, 1].
    pub fn noise(&self, x: f64, y: f64) -> f64 {
        kadr_core::hash::pcg32_hash(self.seed, Self::cell_index(self.cell_size(), x, y)) as f64 / u32::MAX as f64
    }
}

/// The grain's weight `4·Y·(1 − Y)` with `Y` clamped into [0, 1]: no grain
/// in pure black or white.
pub fn grain_weight(y: f64) -> f64 {
    let y = y.clamp(0.0, 1.0);
    4.0 * y * (1.0 - y)
}
```

```rust
/// A layer's effects as one fused chain of point operations on
/// unpremultiplied RGB (the contract's "Point operations"): consecutive
/// `ColorAdjust`s fold into one affine map — every adjust step is affine,
/// exposure `(c^2.4 · 2^ev)^(1/2.4)` being `c · 2^(ev/2.4)` for `c ≥ 0` —
/// then the other primitives in list order, the clamp once at the end.
/// Built once per layer and frame; run inside the layer's one pass.
struct PointFx {
    ops: Vec<Op>,
    /// Some op reads the pixel's canvas position (vignette, grain).
    spatial: bool,
}

enum Op {
    Affine { m: [[f32; 3]; 3], t: [f32; 3] },
    /// `ToneCurve::table`.
    Curve(Box<[f32; 256]>),
    /// The two hue offsets already scaled by their amounts, and `0.25 · balance`.
    Split { shadow: [f32; 3], highlight: [f32; 3], bias: f32 },
    /// The canvas centre, 1 / half the canvas diagonal, the smoothstep's edges, the amount.
    Vignette { cx: f64, cy: f64, inv_r: f64, e0: f32, e1: f32, amount: f32 },
    /// `pcg32_stream(seed)`, the cell side in canvas pixels, the amount.
    Grain { stream: u64, size: f64, amount: f32 },
}

type Affine3 = ([[f64; 3]; 3], [f64; 3]);

fn adjust_affine(a: &ColorAdjust) -> Affine3 {
    const LUMA: [f64; 3] = [0.2126, 0.7152, 0.0722];
    let e = (a.exposure as f64 / 2.4).exp2();
    let k = a.contrast as f64;
    let (t, u, s) = (a.temperature as f64, a.tint as f64, a.saturation as f64);
    let wb = [1.0 + 0.1 * t, 1.0 - 0.05 * u, 1.0 - 0.1 * t];
    // c → wb · (k·e·c + 0.5·(1 − k)), then saturation S = s·I + (1 − s)·1·lumaᵀ.
    let sat = |r: usize, c: usize| if r == c { s } else { 0.0 } + (1.0 - s) * LUMA[c];
    let m = std::array::from_fn(|r| std::array::from_fn(|c| sat(r, c) * wb[c] * k * e));
    let t = std::array::from_fn(|r| (0..3).map(|c| sat(r, c) * wb[c] * 0.5 * (1.0 - k)).sum());
    (m, t)
}

/// `later` after `earlier`: `m2·(m1·c + t1) + t2`.
fn compose((m1, t1): Affine3, (m2, t2): Affine3) -> Affine3 {
    (
        std::array::from_fn(|r| std::array::from_fn(|c| (0..3).map(|n| m2[r][n] * m1[n][c]).sum())),
        std::array::from_fn(|r| (0..3).map(|n| m2[r][n] * t1[n]).sum::<f64>() + t2[r]),
    )
}

fn affine_op((m, t): Affine3) -> Op {
    Op::Affine { m: m.map(|r| r.map(|v| v as f32)), t: t.map(|v| v as f32) }
}

const LUMA_F32: [f32; 3] = [0.2126, 0.7152, 0.0722];

#[inline(always)]
fn luma_f32(c: [f32; 3]) -> f32 {
    LUMA_F32[0] * c[0] + LUMA_F32[1] * c[1] + LUMA_F32[2] * c[2]
}

#[inline(always)]
fn smoothstep_f32(e0: f32, e1: f32, x: f32) -> f32 {
    let t = ((x - e0) / (e1 - e0)).clamp(0.0, 1.0);
    t * t * (3.0 - 2.0 * t)
}

impl PointFx {
    /// `None` when every primitive is neutral: the chain — its clamp too —
    /// is skipped. `canvas`: the canvas size in pixels.
    fn of(effects: &[Effect], canvas: (f64, f64)) -> Option<PointFx> {
        let mut ops = Vec::new();
        let mut acc: Option<Affine3> = None;
        for e in effects.iter().filter(|e| !e.is_neutral()) {
            if let Effect::ColorAdjust(a) = e {
                let next = adjust_affine(a);
                acc = Some(acc.map_or(next, |earlier| compose(earlier, next)));
                continue;
            }
            if let Some(a) = acc.take() {
                ops.push(affine_op(a));
            }
            match e {
                Effect::ToneCurve(c) => ops.push(Op::Curve(Box::new(c.table()))),
                Effect::SplitTone(s) => {
                    let scaled = |hue: f32, amount: f32| hue_offset(hue as f64).map(|v| (v * amount as f64) as f32);
                    ops.push(Op::Split { shadow: scaled(s.shadow_hue_deg, s.shadow_amount), highlight: scaled(s.highlight_hue_deg, s.highlight_amount), bias: 0.25 * s.balance });
                }
                Effect::Vignette(v) => ops.push(Op::Vignette {
                    cx: canvas.0 / 2.0,
                    cy: canvas.1 / 2.0,
                    inv_r: 2.0 / (canvas.0 * canvas.0 + canvas.1 * canvas.1).sqrt(),
                    e0: v.midpoint,
                    e1: v.midpoint + v.feather.max(0.01),
                    amount: v.amount,
                }),
                Effect::Grain(g) => ops.push(Op::Grain { stream: pcg32_stream(g.seed), size: g.cell_size(), amount: g.amount }),
                // A primitive this renderer does not implement yet is skipped.
                _ => {}
            }
        }
        if let Some(a) = acc {
            ops.push(affine_op(a));
        }
        if ops.is_empty() {
            return None;
        }
        let spatial = ops.iter().any(|o| matches!(o, Op::Vignette { .. } | Op::Grain { .. }));
        Some(PointFx { ops, spatial })
    }

    /// On a premultiplied sample whose output pixel centre lies at canvas
    /// position `pos`: unpremultiply, the ops, clamp once, premultiply.
    #[inline(always)]
    fn apply(&self, s: [f32; 4], pos: (f64, f64)) -> [f32; 4] {
        let a = s[3];
        if a == 0.0 {
            return s;
        }
        let mut c = [s[0] / a, s[1] / a, s[2] / a];
        for op in &self.ops {
            match op {
                Op::Affine { m, t } => c = std::array::from_fn(|r| m[r][0] * c[0] + m[r][1] * c[1] + m[r][2] * c[2] + t[r]),
                Op::Curve(table) => c = c.map(|v| tone_lookup(table, v)),
                Op::Split { shadow, highlight, bias } => {
                    let yb = (luma_f32(c) + bias).clamp(0.0, 1.0);
                    let (ws, wh) = ((1.0 - yb) * (1.0 - yb), yb * yb);
                    c = std::array::from_fn(|k| c[k] + ws * shadow[k] + wh * highlight[k]);
                }
                Op::Vignette { cx, cy, inv_r, e0, e1, amount } => {
                    let (dx, dy) = (pos.0 - cx, pos.1 - cy);
                    let d = ((dx * dx + dy * dy).sqrt() * inv_r) as f32;
                    let v = 1.0 - amount * smoothstep_f32(*e0, *e1, d);
                    c = c.map(|x| x * v);
                }
                Op::Grain { stream, size, amount } => {
                    let h = pcg32_at(*stream, Grain::cell_index(*size, pos.0, pos.1)) as f32 / u32::MAX as f32;
                    let y = luma_f32(c).clamp(0.0, 1.0);
                    let n = (h - 0.5) * amount * 4.0 * y * (1.0 - y);
                    c = c.map(|x| x + n);
                }
            }
        }
        let o = |v: f32| v.clamp(0.0, 1.0) * a;
        [o(c[0]), o(c[1]), o(c[2]), a]
    }
}
```

```rust
fn luma(c: [f64; 3]) -> f64 {
    0.2126 * c[0] + 0.7152 * c[1] + 0.0722 * c[2]
}

/// The hue `h` (degrees, mod 360) at full saturation and value, minus its Rec.709 luma.
fn hue_minus_luma(h: f64) -> [f64; 3] {
    let h = h.rem_euclid(360.0) / 60.0;
    let x = 1.0 - (h % 2.0 - 1.0).abs();
    let rgb = match h as u32 {
        0 => [1.0, x, 0.0],
        1 => [x, 1.0, 0.0],
        2 => [0.0, 1.0, x],
        3 => [0.0, x, 1.0],
        4 => [x, 0.0, 1.0],
        _ => [1.0, 0.0, x],
    };
    let y = luma(rgb);
    rgb.map(|v| v - y)
}

/// Effects on unpremultiplied colour, in list order: `rgb / a` → chain →
/// clamp once → `× a`. `pos`: the canvas position of the output pixel
/// centre; `canvas`: the canvas size.
fn apply_effects(effects: &[Effect], s: Px, pos: (f64, f64), canvas: (f64, f64)) -> Px {
    // "Neutral primitives are no-ops: a chain of nothing else is skipped, clamp included."
    if effects.iter().all(Effect::is_neutral) {
        return s;
    }
    let a = s[3];
    // "A sample with a = 0 stays as it is (the chain is skipped)."
    if a == 0.0 {
        return s;
    }
    let mut c = [s[0] / a, s[1] / a, s[2] / a];
    for e in effects {
        match e {
            Effect::ColorAdjust(adj) => {
                // Exposure: linear light with a pure 2.4 power (odd extension for negatives, only
                // reachable in a chain, before the single final clamp).
                let gain = 2f64.powf(adj.exposure as f64);
                for v in c.iter_mut() {
                    let m = v.abs().powf(2.4) * gain;
                    *v = if *v < 0.0 { -m.powf(1.0 / 2.4) } else { m.powf(1.0 / 2.4) };
                }
                for v in c.iter_mut() {
                    *v = (*v - 0.5) * adj.contrast as f64 + 0.5;
                }
                let (t, u) = (adj.temperature as f64, adj.tint as f64);
                c[0] *= 1.0 + 0.1 * t;
                c[2] *= 1.0 - 0.1 * t;
                c[1] *= 1.0 - 0.05 * u;
                let y = luma(c);
                for v in c.iter_mut() {
                    *v = y + (*v - y) * adj.saturation as f64;
                }
            }
            Effect::ToneCurve(curve) => {
                let table = curve.table();
                for v in c.iter_mut() {
                    let x = v.clamp(0.0, 1.0) * 255.0;
                    let i = (x.floor() as usize).min(254);
                    let (t0, t1) = (table[i] as f64, table[i + 1] as f64);
                    *v = t0 + (t1 - t0) * (x - i as f64);
                }
            }
            Effect::SplitTone(st) => {
                let yb = (luma(c) + 0.25 * st.balance as f64).clamp(0.0, 1.0);
                let (ws, wh) = ((1.0 - yb) * (1.0 - yb), yb * yb);
                let (ds, dh) = (hue_minus_luma(st.shadow_hue_deg as f64), hue_minus_luma(st.highlight_hue_deg as f64));
                for k in 0..3 {
                    c[k] += st.shadow_amount as f64 * ws * ds[k] + st.highlight_amount as f64 * wh * dh[k];
                }
            }
            Effect::Vignette(v) => {
                let half_diagonal = (canvas.0 * canvas.0 + canvas.1 * canvas.1).sqrt() / 2.0;
                let d = ((pos.0 - canvas.0 / 2.0).powi(2) + (pos.1 - canvas.1 / 2.0).powi(2)).sqrt() / half_diagonal;
                let (e0, e1) = (v.midpoint as f64, v.midpoint as f64 + (v.feather as f64).max(0.01));
                let t = ((d - e0) / (e1 - e0)).clamp(0.0, 1.0);
                let gain = 1.0 - v.amount as f64 * t * t * (3.0 - 2.0 * t);
                for x in c.iter_mut() {
                    *x *= gain;
                }
            }
            Effect::Grain(g) => {
                let size = if g.size.is_finite() && g.size >= 1.0 { g.size as f64 } else { 1.0 };
                let (cx, cy) = ((pos.0 / size).floor() as i64, (pos.1 / size).floor() as i64);
                let index = ((cy as u32 as u64) << 32) | cx as u32 as u64;
                let h = kadr_core::hash::pcg32_hash(g.seed, index) as f64 / u32::MAX as f64;
                let y = luma(c).clamp(0.0, 1.0);
                let n = (h - 0.5) * g.amount as f64 * 4.0 * y * (1.0 - y);
                for x in c.iter_mut() {
                    *x += n;
                }
            }
            _ => {}
        }
    }
    [c[0].clamp(0.0, 1.0) * a, c[1].clamp(0.0, 1.0) * a, c[2].clamp(0.0, 1.0) * a, a]
}
```

```rust
/// The grain seed of frame `ctx.frame`: the effect's (from its id) mixed
/// with the frame's time — new grain every frame, the same while paused and

/// The grain cell for a canvas: `GRAIN_CELL_PER_1080` per 1080 lines, at least 1 pixel.

/// `preset` at intensity `k` (D4): its correction, curve, split tone,
/// vignette and grain, in that order, each moved from neutral by `k` — the
/// curve's y to `x + k·(y − x)`, clamped into [0, 1] and kept rising; the
/// correction from `ColorAdjust::NEUTRAL`; amounts × k — neutral ones dropped.
pub fn look_effects(preset: &LookPreset, k: f64, ctx: &CompileCtx) -> Vec<Effect> {
    let lerp = |neutral: f64, v: f64| neutral + k * (v - neutral);
    let mut out = Vec::new();
    let a = &preset.adjust;
    let adjust = ColorAdjust {
        exposure: lerp(0.0, a.exposure) as f32,
        contrast: lerp(1.0, a.contrast).max(0.0) as f32,
        saturation: lerp(1.0, a.saturation).max(0.0) as f32,
        temperature: lerp(0.0, a.temperature).clamp(-1.0, 1.0) as f32,
        tint: lerp(0.0, a.tint).clamp(-1.0, 1.0) as f32,
    };
    if !adjust.is_neutral() {
        out.push(Effect::ColorAdjust(adjust));
    }
    let mut rising = 0.0f64;
    let mut points = Vec::with_capacity(preset.curve.len());
    for &(x, y) in &preset.curve {
        rising = lerp(x, y).clamp(0.0, 1.0).max(rising);
        points.push((x as f32, rising as f32));
    }
    let curve = ToneCurve { points };
    if !curve.is_neutral() {
        out.push(Effect::ToneCurve(curve));
    }
    if let Some(s) = preset.split_tone {
        let split = SplitTone {
            shadow_hue_deg: s.shadow_hue as f32,
            shadow_amount: (s.shadow_amount * k) as f32,
            highlight_hue_deg: s.highlight_hue as f32,
            highlight_amount: (s.highlight_amount * k) as f32,
            balance: s.balance as f32,
        };
        if !split.is_neutral() {
            out.push(Effect::SplitTone(split));
        }
    }
    let vignette = Vignette { amount: (preset.vignette * k).min(1.0) as f32, midpoint: LOOK_VIGNETTE_MIDPOINT as f32, feather: LOOK_VIGNETTE_FEATHER as f32 };
    if !vignette.is_neutral() {
        out.push(Effect::Vignette(vignette));
    }
    let grain = Grain { amount: (preset.grain * k) as f32, size: grain_cell(ctx.canvas) as f32, seed: frame_seed(ctx) };
```

```rust
/// effects applied in list order, in the crop window the clip has at `t`
/// (its animated crop). Unknown recipes, newer versions and unknown
/// variants are skipped; strength 0 compiles nothing (§3).
pub fn place_with_effects(clip: &Clip, t: Time, canvas: SizeU, base: Placement) -> Placement {
    if clip.effects.is_empty() || clip.duration() <= Time::ZERO {
        return base;
    }

/// Every enabled, known effect of `clip` at `t`, in list order (spec §3,
/// D3): its placement delta composed over `base` in the crop `window`
/// (`crop_window` of the clip's state at `t`), its colour primitives
/// collected — `clip_layer` puts them after the inspector's correction.
pub(crate) fn apply_effects(clip: &Clip, t: Time, canvas: SizeU, base: Placement, window: (f64, f64, f64, f64)) -> (Placement, Vec<Effect>) {
    // A clip of no length shows nothing (and maps no source time).
    if clip.effects.is_empty() || clip.duration() <= Time::ZERO {
        return (base, Vec::new());
    }
    let source_time = SourceTime(clip.source_time_at(t));
    let aspect = if base.size.y > 0.0 { base.size.x as f64 / base.size.y as f64 } else { 1.0 };
    let secs = clip.duration().as_secs_f64();
    let speed = Some(clip.speed()).filter(|s| s.is_finite() && *s > 0.0).unwrap_or(1.0);
    let mut placement = base;
    let mut colour = Vec::new();
    for e in clip.effects.iter().filter(|e| e.enabled) {
        // Unknown recipe, newer version or variant: kept, never run (spec §2)
        // — nor are its `fx:` tracks read. Only declared number parameters of
        // the clip's own effects are looked up, so orphan tracks never count.
        let Some(def) = definition(e) else { continue };
        let params = Params::resolve(def.params, &e.params, |key| clip.animation.fx_value_at(e.id, key, source_time));
        if params.is_off() {
            continue;
        }
        // Seconds of the whole progress range at the clip's length: the
        // effect's own clock `progress × clip_secs` runs on across a split.
        let span = (e.progress.1 - e.progress.0).abs();
        let clip_secs = if span > 1e-9 { secs / span } else { secs };
        let progress = effect_progress(clip, e, t);
        if !progress.is_finite() || !clip_secs.is_finite() {
            continue;
        }
        let ctx = CompileCtx { progress, clip_secs, source_time, speed, canvas, aspect, window, frame: t, seed: effect_seed(e) };
        let compiled = (def.compile)(&params, &ctx);
        placement = compiled.placement.apply(&placement);
        colour.extend(compiled.effects);
    }
    (placement, colour)
}
```

```rust
/// One card of the tab (spec §6.1, D5): a recipe, or one of its variants —
/// a Look preset — with its own id (`look:warm`), name, picture and apply.
/// Built only from the registry (`cards_of`, `Card::parse`).
#[derive(Clone, Copy)]
pub struct Card {
    pub def: &'static RecipeDef,
    pub variant: Option<&'static str>,
}

impl PartialEq for Card {
    fn eq(&self, o: &Card) -> bool {
        self.def.id == o.def.id && self.variant == o.variant
    }
}

impl Eq for Card {}

impl std::hash::Hash for Card {
    fn hash<H: std::hash::Hasher>(&self, h: &mut H) {
        std::hash::Hash::hash(&(self.def.id, self.variant), h);
    }
}

impl std::fmt::Debug for Card {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        write!(f, "Card({})", self.id())
    }

    /// `smooth_zoom`, or `look:warm` for a variant.
    pub fn id(&self) -> String {
        match self.variant {
            Some(v) => format!("{}:{v}", self.def.id),
            None => self.def.id.to_string(),
        }
    }

    /// The card an id from the tab names; `None` for one this build lacks.
    pub fn parse(id: &str) -> Option<Card> {
        let (recipe, variant) = match id.split_once(':') {
            Some((r, v)) => (r, Some(v)),
            None => (id, None),
        };
        cards_of(kadr_effects::recipe(recipe)?).into_iter().find(|c| c.variant == variant)
    }

    /// i18n key of the card's name: the variant's (`fx.look.warm`) or the recipe's.
    pub fn name_key(&self) -> String {
        match (self.def.variants, self.variant) {
            (Some(key), Some(v)) => self.def.option_name_key(key, v),
            _ => self.def.name_key(),
        }
    }

    /// «Обычно» with the card's variant.
    pub fn fresh(&self, clip: &Clip, at: Time) -> AppliedEffect {
```
